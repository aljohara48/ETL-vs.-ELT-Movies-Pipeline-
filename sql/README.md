# SQL Transformations

The original ELT workflow applied transformation logic directly in PostgreSQL
using pgAdmin after the raw data had been loaded into staging tables.

The project report documents operations such as:
- removing duplicates,
- standardizing text,
- handling null values,
- cleaning year values,
- rounding ratings,
- and populating final tables.

The original SQL script was not among the recovered source-code files, so it
is intentionally not reconstructed here.
